# 🥖 Trabajo Práctico Prolog — Panadería

Este programa modela una panadería en Prolog, donde podés consultar sobre tipos de pan, ciclos de producción, ingredientes y realizar cálculos relacionados con costos de producción.

---

## 📁 Archivos

| Archivo         | Contenido                                      |
|----------------|------------------------------------------------|
| `tp_panaderia.pl` | Hechos y reglas en Prolog para resolver las consignas del trabajo práctico. |

---

## ▶️ Cómo ejecutar

1. Abrí tu intérprete de Prolog (por ejemplo, SWI-Prolog).
2. Cargá el archivo:
   ```prolog
   ?- [tp_panaderia].
