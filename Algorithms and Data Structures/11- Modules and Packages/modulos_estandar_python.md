# Módulos Estándar de Python

| **Módulo estándar**           | **Contenido general** |
|------------------------------|------------------------|
| `os`                         | Interfaz de acceso a funciones del sistema operativo. |
| `glob`                       | Funciones para crear listas de archivos con caracteres "comodines" (wildcards). |
| `sys`                        | Variables del entorno del shell, acceso a argumentos de línea de comandos, redirección de entrada/salida. |
| `re`                         | Reconocimiento de patrones (expresiones regulares) en strings. |
| `math`                       | Funciones matemáticas típicas (logarítmicas, trigonométricas, etc.). |
| `random`                     | Números aleatorios y decisiones aleatorias. |
| `urllib.request`             | Recuperación de datos desde una URL. |
| `smtplib`, `poplib`          | Envío y recepción de mails. |
| `email`                      | Gestión integral de mensajes de email, incluyendo decodificación y attachments. |
| `datetime`                   | Manipulación de fechas y horas. |
| `zlib`, `gzip`, `bz2`, `zipfile`, `tarfile` | Compresión y descompresión de datos en distintos formatos. |
| `timeit`, `profile`, `pstats` | Medición de rendimiento de programas, funciones o bloques de código. |
| `doctest`                    | Validación de tests en strings de documentación. |
| `unittest`                   | Tests estructurados en archivos separados. Más potente que `doctest`. |
| `xmlrpc.client`, `xmlrpc.server` | Llamadas a procedimientos remotos (RPC). |
| `xml.dom`, `xml.sax`         | Parsing de documentos XML. |
| `csv`                        | Lectura y escritura de archivos CSV. |
| `gettext`, `locale`, `codecs`| Soporte de "internationalization" (i18n). |
